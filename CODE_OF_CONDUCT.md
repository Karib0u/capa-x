# Code of conduct

## Our standard

Project participation should be professional, constructive, and welcoming.
Contributors are expected to:

- discuss technical work in good faith;
- critique ideas and code without attacking people;
- respect different experience levels and communication styles;
- avoid harassment, discrimination, threats, and unwanted personal attention;
- handle malware, private reports, and sensitive samples responsibly;
- accept maintainer decisions about scope while remaining free to disagree
  respectfully.

Examples of unacceptable behavior include personal insults, discriminatory
language, deliberate intimidation, publishing private information, sexualized
conduct, sustained disruption, and retaliation against someone who reports a
problem.

## Scope

This standard applies in repository issues, pull requests, discussions,
reviews, and other spaces where someone represents the project.

## Enforcement

Report conduct concerns privately to the repository maintainers. Contact the
repository owner through their GitHub profile to request a private channel,
and do not include sensitive details in a public message.

Maintainers may edit or remove contributions and may temporarily or
permanently restrict participation when behavior is harmful to the project or
its community. Reports will be handled as privately as practical, and
retaliation against reporters is not permitted.

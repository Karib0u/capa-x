#   python3 scripts/bench.py --samples scripts/corpus-bench.txt \
#       --capa-cli target/release/capa-x --jobs 1,2,4,default --runs 5 --markdown
#
# This is a *performance* list, not a correctness one: nothing here is
# compared against Python capa. It exists so that two benchmark runs, months
# apart, measure the same work -- a speedup claim over a corpus that quietly
# changed is not a measurement.

# size drives loading and recovery, function count drives the two parallel

# parsed. Sizes are from the pinned testfiles commit in PINNED.md; keep the
# annotations true if you re-pick a row.

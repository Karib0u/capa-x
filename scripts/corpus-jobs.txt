# Determinism corpus -- the five samples CI compares at `--jobs 1` against
# `--jobs 2` and `--jobs 4` on every push (docs/BENCHMARKS.md, gate J2).
# Paths are relative to tests/testfiles/, same as every other corpus list.
#
#   python3 scripts/determinism.py --samples scripts/corpus-jobs.txt \
#       --capa-cli target/release/capa-x --jobs 1,2,4 --repeat 5
#
# Small on purpose: this is a *cheap* per-push guard, and the property it
# checks -- that the parallel join is ordered by address rather than by
# completion -- is a property of the code, not of any particular sample. A
# sample can only expose it by having enough functions to distribute, which is
# the one thing every row here has. The full 200-sample comparison is a
# pre-merge run, not a CI job.
#
# One row per input shape the parallel seams see: PE32, PE32+, ELF, packed,
# and a large image whose functions are numerous enough that workers finish
# far out of order.
